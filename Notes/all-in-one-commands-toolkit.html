12. Troubleshooting Flowcharts (Quick Logic)

"No Internet" Complaint

Physical cable/Wi-Fi → ipconfig (IP mila?) → ping gateway → ping 8.8.8.8 → nslookup google.com → browser test

"Computer Slow"

Task Manager (CPU/RAM/Disk) → Startup apps → Malware scan → Event Viewer logs → Disk health (chkdsk) → Hardware check

"Can't Access Server/Application"

ping server IP → telnet/Test-NetConnection port → check VPN/firewall/ACL → check service status on server → check application logs

"Camera Offline"

Power/PoE check → cable check → ping camera IP → check IP conflict (arp) → NVR camera management page → check NVR network/VPN

"Email Not Working"

Internet check → webmail test → Outlook profile/account → MFA/password → DNS MX record → M365 service health
