1. System Administrator Role Overview

Ek System Administrator ka kaam hota hai company ke IT infrastructure ko manage, secure aur available rakhna:

  • Servers — Windows Server / Linux servers install, configure, maintain
  • Users & Access — Active Directory, permissions, groups
  • Network Services — DNS, DHCP, File sharing, Print services
  • Backup & Recovery — data protection, disaster recovery
  • Security — patching, firewall, antivirus, monitoring
  • Virtualization — VMs, Hyper-V, VMware
  • Automation — scripting (PowerShell/Bash) se repetitive tasks automate karna
Golden Rule: Document everything, test changes before production, always keep verified backups.

4. Active Directory (AD DS) Concepts Windows Server

TermMeaning
DomainLogical group of network objects (users, computers) — central management
Domain Controller (DC)Server jo AD database (NTDS.dit) host karta hai aur authentication karta hai
OU (Organizational Unit)Users/computers ko organize karne ka container — GPO apply karne ke liye
FSMO Roles5 special DC roles: Schema Master, Domain Naming Master, RID Master, PDC Emulator, Infrastructure Master
Forest / TreeMultiple domains ka collection (trust relationship ke saath)
ReplicationMultiple DCs ke beech data sync (multi-master)
TrustEk domain doosre domain ke users ko access allow karta hai

Common AD Tasks

  • New user/computer create, disable, delete
  • Group create (Security vs Distribution)
  • Password policy set (via Default Domain Policy)
  • Account lockout policy configure
  • AD backup — System State backup via wbadmin

6. Group Policy (GPO) Windows Server

GPO se centrally settings/restrictions push ki jaati hain users/computers par (OU level par apply hoti hain).

  • Password policy, screen lock timeout
  • Software deployment/restriction
  • Drive mapping, printer deployment
  • Security settings, firewall rules
CommandPurpose
gpupdate /forcePolicy turant apply karo (client side)
gpresult /h report.htmlApplied GPOs ka detailed report
Get-GPO -AllSab GPOs list (PowerShell)
New-GPO -Name "Restrict-USB"New GPO create
New-GPLink -Name "Restrict-USB" -Target "OU=Sales,DC=company,DC=local"GPO ko OU se link karo
GPO Order of Precedence: Local → Site → Domain → OU (last applied wins = LSDOU)

17. Security (Firewall / Patching)

Windows Firewall Windows

netsh advfirewall show allprofiles
netsh advfirewall firewall add rule name="Allow HTTP" dir=in action=allow protocol=TCP localport=80
New-NetFirewallRule -DisplayName "Allow SSH" -Direction Inbound -Protocol TCP -LocalPort 22 -Action Allow

Linux Firewall Linux

# firewalld (RHEL/CentOS)
firewall-cmd --list-all
firewall-cmd --add-port=80/tcp --permanent
firewall-cmd --reload

# UFW (Ubuntu)
ufw status
ufw allow 22/tcp
ufw enable

# iptables (legacy)
iptables -L -n

Patch Management

  • Windows: WSUS (Windows Server Update Services), Windows Update settings, Get-WindowsUpdate
  • Linux: apt update && apt upgrade / yum update — scheduled patching windows follow karo
  • Best Practice: Pehle test/staging environment mein patch apply karo, phir production mein
