2. Camera Types & Selection

TypeBest Use Case
Dome CameraIndoor, discreet, vandal-resistant options available
Bullet CameraOutdoor, long-range visible deterrent

Key Specs to Consider

  • Resolution: 2MP (1080p) minimum, 4MP/8MP (4K) for detail-critical areas
  • IR Range: Night vision distance (e.g. 30m, 50m)
  • IP Rating: IP66/IP67 for outdoor weatherproofing
  • Lens (Focal Length): Wide angle (2.8mm) vs zoomed (8mm+)
  • WDR (Wide Dynamic Range): Backlight/high-contrast scenes ke liye

3. Cabling & Power

IP Camera (PoE) Cabling

  • Cable: Cat5e / Cat6 UTP — max run 100 meters per segment
  • PoE Standards: 802.3af (15.4W), 802.3at (PoE+, 30W), 802.3bt (PoE++, 60-90W for PTZ)
  • 100m se zyada distance ke liye: PoE extender/repeater ya fiber + media converter use karo

Analog Camera (Coax) Cabling

  • Cable: RG59 Siamese (video + power combined)
  • Max run: ~300m (RG59), better with RG6
  • Separate 12V DC power supply required (ya centralized power box)

Best Practices

  • Cable ko conduit/trunking mein daalo — weather aur physical damage se bachao
  • Power cables se electrical interference avoid karne ke liye alag route rakho
  • Outdoor connections ko waterproof connectors/junction box se seal karo
  • Surge protector lagao lightning-prone areas mein

4. Camera Placement Best Practices

  1. Entry/exit points, cash counters, parking, perimeter — high-priority areas identify karo
  2. Camera height: 2.5–3m (indoor), 3–4m (outdoor) — tampering se bachne ke liye
  3. Direct sunlight/strong backlight camera ke saamne avoid karo (WDR camera use karo agar zaroori ho)
  4. Overlap coverage rakho blind spots avoid karne ke liye
  5. Entry points par face-level angle rakho (identification ke liye), overview ke liye wide angle
  6. IR cameras ke liye — glass/reflective surface ke bahut close mat lagao (IR reflection issue)

5. NVR/DVR Installation

Initial Setup Steps (Hikvision NVR)

  1. HDD install karo NVR ke andar (SATA connect + screw mount)
  2. Monitor + mouse connect karo (HDMI/VGA)
  3. Power on — first-time wizard start hoga
  4. Admin password set karo (strong password — default password kabhi mat rakho)
  5. Date/Time zone set karo (NTP sync recommended)
  6. HDD ko "Init/Format" karo agar naya hai
  7. Cameras auto-detect honge (PoE ports mein connect hone par) — ya manually "Add Camera" se add karo
  8. Recording schedule set karo (continuous / motion-based / schedule-based)
  9. Network settings configure karo (IP, gateway, DNS)

Recording Modes

ModeDescription
Continuous24/7 recording — sabse zyada storage use karta hai
Motion DetectionSirf movement detect hone par record
Event/Alarm-basedSensor/line-crossing/intrusion trigger par record
ScheduledSpecific time slots mein record (e.g. office hours ke baad)

6. Network & IP Setup

IP Camera / NVR Networking

  • Har camera aur NVR ko ek dedicated VLAN mein rakho (office traffic se separate) — bandwidth aur security dono behtar
  • Static IP recommended cameras/NVR ke liye (DHCP se IP change ho sakta hai, connection break ho sakta hai)
  • Example scheme: NVR → 192.168.50.1, Cameras → 192.168.50.101–150

Bandwidth Estimation (per camera, approx.)

ResolutionBitrate (H.264)Bitrate (H.265)
1080p (2MP)~4 Mbps~2 Mbps
4MP~6 Mbps~3 Mbps
4K (8MP)~12-16 Mbps~6-8 Mbps

H.265+ codec use karo — bandwidth aur storage dono kam karta hai bina quality loss ke.

7. Hikvision Configuration

SADP Tool (Camera/NVR Discovery)

SADP (Search Active Device Protocol) tool se network mein sab Hikvision devices detect hote hain — IP change, activation, aur password reset ke liye use hota hai.

  1. SADP tool install/open karo (Windows PC par)
  2. Device list mein sab connected Hikvision devices dikhenge
  3. Inactive device select karo → password activate karo
  4. IP address, subnet mask, gateway modify kar sakte ho seedha SADP se

Default Access

ItemDetail
Default IP (camera)192.168.1.64 (typical, model-dependent)
Web login port80 (HTTP)
HTTPS port443
Client software port8000
RTSP port (streaming)554

Web Interface Configuration Path

  • Configuration → Network → Basic Settings — IP/DNS set
  • Configuration → Video/Audio — resolution, bitrate, frame rate
  • Configuration → Storage → Schedule — recording schedule
  • Configuration → Event → Motion Detection — sensitivity, detection area
  • Configuration → User Management — operator/viewer accounts add karo

Adding Camera to NVR (via Web GUI)

Configuration → Camera → Camera Management → Add — camera IP, port (8000), username/password enter karo, ya "Add Online Device" se auto-detected list se select karo.

8. Recording & Storage Calculation

Basic Formula

Storage (GB) = Bitrate (Mbps) × 3600 × 24 × Days ÷ 8 ÷ 1024 × Number of Cameras

Example — Quick Reference (per camera, 24/7, H.265)

ResolutionApprox. Storage/DayStorage for 30 Days
1080p (2MP)~20 GB~600 GB
4MP~30 GB~900 GB
4K (8MP)~60-80 GB~1.8-2.4 TB

Note: Motion-detection recording se storage requirement kaafi kam ho jata hai (30-70% tak reduce ho sakta hai).

9. Remote Viewing & Port Forwarding

Option 1 — Hik-Connect / P2P (Easiest, no port forwarding needed)

  1. NVR settings mein Hik-Connect (P2P) enable karo
  2. QR code scan karo mobile app (Hik-Connect) se
  3. Device serial number + verification code register karo
  4. Cloud ke through remote access mil jaata hai bina router config ke

Option 2 — Port Forwarding (Static IP / DDNS)

PortPurpose
80HTTP web access
8000Client software (iVMS-4200) access
554RTSP video streaming
  1. Router mein port forwarding rule add karo (external port → NVR internal IP:port)
  2. Agar dynamic public IP hai to DDNS (No-IP, DynDNS, ya Hikvision's own DDNS) setup karo
  3. NVR mein DDNS enable karo: Configuration → Network → DDNS
  4. Firewall par sirf required ports allow karo — poora range open mat karo
Security Tip: Default ports change kar do (e.g. 8000 → 28000) — random bot scans se bachne ke liye.

Mobile/Client Apps

  • Hik-Connect — mobile app, cloud P2P
  • iVMS-4200 — desktop client, multi-site professional management

10. Users, Permissions & Motion Alerts

User Roles

RoleAccess
AdministratorFull control — settings, users, storage, network
OperatorLive view, playback, PTZ control — settings change nahi
Viewer/GuestSirf live view — playback/export nahi

Motion Detection Setup

  1. Configuration → Event → Basic Event → Motion Detection mein jao
  2. Detection area draw karo (grid select) — jahan motion detect karna hai
  3. Sensitivity level set karo (zyada high se false alerts badh sakte hain)
  4. Linkage action set karo: recording start, email alert, buzzer, app notification
  5. Schedule set karo (kab-kab motion detection active rahe)

Advanced Analytics (supported models)

  • Line Crossing Detection — defined line cross karne par alert
  • Intrusion Detection — defined zone mein entry par alert
  • Face Detection/Recognition — identification/counting
  • People Counting — footfall analysis

11. Multi-Branch Centralized Monitoring

Multiple branches ke CCTV ko Head Office se centrally monitor karne ke liye:

  1. Har branch ka NVR site-to-site VPN ya dedicated link se HQ network se connected ho
  2. HQ par iVMS-4200 (ya Hik-Central) install karo
  3. Har branch ke NVR ko client software mein add karo (device IP, port 8000, credentials)
  4. Sab cameras ek hi dashboard se monitor ho sakte hain (live view + playback)
  5. Bandwidth planning zaroori hai — HQ se multiple branches ki live streams dekhna bandwidth-heavy ho sakta hai (sub-stream use karo monitoring ke liye, main-stream sirf recording ke liye)
Tip: Live monitoring ke liye "sub-stream" (lower resolution) use karo — bandwidth bachega, recording "main-stream" (full resolution) mein continue rahegi.

12. Maintenance Checklist

Weekly

  • Sab cameras live view check karo (koi offline/blur/dark to nahi)
  • Recording status verify karo (koi gap to nahi)

Monthly

  • Camera lens clean karo (dust/cobweb, especially outdoor)
  • HDD health check karo (S.M.A.R.T. status)
  • Storage space verify karo (retention period maintain ho raha hai ya nahi)
  • Firmware update check karo

Quarterly/Yearly

  • Cable connections check karo (corrosion, loose connectors especially outdoor)
  • PoE switch health check karo
  • Password rotation / security audit
  • UPS battery health check

13. Troubleshooting Guide

ProblemLikely Cause & Fix
Camera offline on NVRCheck power/PoE, cable, camera IP, ping camera IP from NVR network
No video / black screenCamera cable, lens cap, night mode stuck, or camera hardware fault
Blurry/out-of-focus imageLens dirty, focus ring adjust, condensation inside housing
Recording gapsHDD full/failing, recording schedule misconfigured, check HDD health
Remote access not workingCheck internet, port forwarding, DDNS status, Hik-Connect status on NVR
Too many false motion alertsReduce sensitivity, adjust detection area (exclude trees/road), enable smart detection
NVR not detecting new cameraCheck camera IP is on same subnet, correct port (8000), correct credentials, PoE providing power
Night vision not workingIR LEDs faulty, IR cut filter stuck, bright light nearby confusing sensor
All cameras from one branch downBranch PoE switch/router/internet/VPN issue — check upstream network first
Troubleshooting Order: Power → Cable/PoE → Camera IP → LAN → NVR Config → Internet/VPN → Remote Access
